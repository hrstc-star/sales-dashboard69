# แดชบอร์ดยอดขายสาขา — เว็บแอปบนมือถือ

เว็บแอปสำหรับดูยอดขายรายสาขา ติดตั้งลงหน้าจอมือถือได้เหมือนแอปจริง
อัปเดตข้อมูลด้วยการแก้ไฟล์ CSV ไฟล์เดียว ไม่ต้องเขียนโค้ด

---

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ | ต้องแก้ไหม |
|---|---|---|
| `index.html` | ตัวแอปทั้งหมด | ไม่ต้อง |
| `data/sales.csv` | **ไฟล์ข้อมูล — แก้ไฟล์นี้ทุกสัปดาห์** | ใช่ |

| `icons/` | ไอคอนแอป | ไม่ต้อง |

## รูปแบบไฟล์ข้อมูล

`data/sales.csv` ต้องมี 6 คอลัมน์นี้เสมอ เรียงแบบนี้:

```
วันที่,ภาค,ผู้ดูแล,รหัสร้าน,ชื่อสาขา,ยอดขาย
2026-08-01,ภาคอีสาน,คุณชาญวิทย์ (โจ้),B001,ขอนแก่น001,45230.50
```

**กฎสำคัญ**

1. **วันที่ต้องเป็นรูปแบบ `ปี-เดือน-วัน`** เช่น `2026-08-01` (ปี ค.ศ. เท่านั้น ไม่ใช่ พ.ศ.)
2. **ยอดขายใส่ตัวเลขล้วน** ไม่ต้องมีสัญลักษณ์ ฿ (มีลูกน้ำคั่นหลักได้)
3. **รหัสร้านที่ลงท้าย `-01` หรือ `-02`** แอปจะถือว่าเป็นจุดขายย่อยและรวมยอดเข้าร้านหลักให้อัตโนมัติ
4. **ห้ามลบข้อมูลเก่า** — ให้เพิ่มแถวใหม่ต่อท้ายไปเรื่อยๆ ยิ่งสะสมนาน กราฟแนวโน้มยิ่งแม่น
5. บันทึกเป็น **CSV UTF-8** เสมอ ไม่งั้นภาษาไทยจะเพี้ยน

---

## ป้อนข้อมูลแบบไหนดี

แอปรองรับทั้งสองแบบ แต่ให้ผลต่างกัน:

**แบบ ก. ป้อนรายวัน (แนะนำ)** — สัปดาห์ละครั้ง แต่ใส่ครบ 7 แถววันที่
→ ปุ่มเลือกช่วง **1 วัน / 3 วัน / 1 สัปดาห์** ใช้งานได้ครบ
→ เห็นรูปแบบยอดขายตามวันในสัปดาห์ เช่น วันอาทิตย์ตกเท่าไร

**แบบ ข. ป้อนสัปดาห์ละตัวเลขเดียว** — 1 แถวต่อสาขาต่อสัปดาห์
→ ยังได้กราฟแนวโน้ม แต่ปุ่มเลือกช่วงจะซ่อนไปเอง เพราะไม่มีข้อมูลรายวันให้แบ่ง

---

## อัปเดตข้อมูลรายสัปดาห์ (ทำ 4 ขั้นตอน ~3 นาที)

1. เปิด `data/sales.csv` ด้วย Excel
2. วางข้อมูลสัปดาห์ใหม่ **ต่อท้ายแถวเดิม** (อย่าลบของเก่า)
3. `File → Save As` → เลือก **CSV UTF-8 (Comma delimited)**
4. อัปโหลดทับไฟล์เดิมบน GitHub → Vercel อัปเดตเองใน ~30 วินาที

> เปิดแอปบนมือถือแล้วดึงหน้าจอลงเพื่อรีเฟรช จะเห็นข้อมูลใหม่ทันที

---

## ถ้าเปิดแอปแล้วขึ้นว่าอ่านไฟล์ไม่ได้

ไล่เช็คตามนี้:

- ไฟล์อยู่ที่ `data/sales.csv` จริงหรือไม่ (ตัวพิมพ์เล็กทั้งหมด)
- หัวตารางครบ 6 คอลัมน์และสะกดตรงตามตัวอย่าง
- บันทึกเป็น CSV UTF-8 ไม่ใช่ `.xlsx`
- วันที่เป็น `2026-08-01` ไม่ใช่ `01/08/2569`

## ถ้าข้อมูลไม่อัปเดตทั้งที่อัปโหลดแล้ว

- เช็คใน Vercel ว่าสถานะ deploy เป็น **Ready** แล้ว
- ปิดแอปแล้วเปิดใหม่ หรือลองเปิดในหน้าต่างไม่ระบุตัวตน
- ยืนยันว่ากด **Commit changes** บน GitHub แล้วจริงๆ
